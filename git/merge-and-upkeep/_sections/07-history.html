{{S}}From e83c5163 to Git 3.0

Git's first commit, e83c5163, is dated 7 April 2005. It is 11 files and 1,244 lines that build seven programs, from update-cache to cat-file, linked against OpenSSL. Its README calls git "the stupid content tracker" and names the two ideas this collection has followed: a content-addressable object database and a "current directory cache", today's index. It already rules out rename tracking, and it puts trust outside git: "the trust has to come from outside", by signing one top-level hash from the code.

The object in git.git today is not the one Linus wrote. Its dates are epoch seconds with a timezone, which the original ctime() code could not produce. Early history was rewritten by convert-cache after the format changed measured here. And the format changed fast. Within a fortnight came recursive trees (9 April), the rename of .dircache to .git (11 April, "That's clearly moronic"), a network-byte-order index (15 April), hashing before compression and the index's trailing checksum (20 April), and tag objects (25 April). Figure {{fig-history}} sets the two designs side by side.

After v0.99 (10 July 2005) the object and index model kept its shape. Everything since is a layer. Packs arrived 11 weeks after the first commit. Junio C Hamano has tagged every release since v0.99.2. Then came offset deltas and packed-refs, the v1.5.0 staging-area interface, smart HTTP, bitmaps, collision-detecting SHA-1, protocol v2 and the commit-graph in the same release, SHA-256 repositories, ort, reftable and geometric maintenance. Each is derived data or an alternative encoding. None replaced the object model, and some, like Z_BEST_SPEED for loose objects since v1.5.3, are only tuning reconstruction.

Some code is older than the format. write_commit_tree() still carries Linus's comment that "the same exact tree merged with a different order of parents will be a _different_ changeset", and alloc_nr() is byte-identical to 2005 from the code. C grew from 34,041 lines at v1.0.0 to 436,044 at v2.55.0, shell (mostly the test suite) from 12,072 to 337,602. 2,335 people have authored commits. Since mid-2024 Patrick Steinhardt has written 27% of non-merge commits, more than three times Junio's count, much of it the refs, object-database and Rust work measured here.

Rust is one 1,571-line crate, gitcore, built by default since v2.55.0 and opted out with NO_RUST; Documentation/BreakingChanges.adoc:201-203 still says to opt in with WITH_RUST=YesPlease, a knob that does not exist (C20). The same document lists Git 3.0: SHA-256 and reftable as defaults for new repositories, main as the default branch, Rust required. It says there is "no plan to deprecate" the SHA-1 format and "no planned release date" for 3.0 from the code.
