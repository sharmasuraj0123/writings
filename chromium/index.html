Chromium

The browser read as a system. One collection for everything written here about Chromium: the JavaScript engine and its compilers, the rendering engine, the machinery that pins and syncs a tree of a few hundred dependencies, and the pipeline that turns a commit into a release every four weeks.

Every entry is one self-contained HTML file. Teardowns cite file paths and line numbers from a checkout of chromium/src at the date in the byline.
