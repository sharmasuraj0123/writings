{{S}}Sequence models and the size of the state

Every autoregressive generator is a Markov process. It has to be: generation is a loop that emits a token and updates something, and the something it updates is the state. The only question — and it is the central architectural question of the last few years — is how big that state is allowed to be, and what it is allowed to forget.

Shannon started here. The ladder of approximations to English in the 1948 paper is a sequence of Markov models whose state is the last k − 1 symbols, and the observation that longer contexts produce more plausible text is the observation the field has been cashing ever since. What stopped the ladder was the bill from Figure {{fig-order-k}}: a 5-gram over a 50,000-token vocabulary has 3.1 × 10²² states, of which any corpus visits a vanishing fraction. Every technique in language modelling before neural networks — back-off, Kneser–Ney smoothing, clustering — was an attempt to make an enormous, almost entirely unobserved transition table behave.

The modern models, sorted by state

Neural sequence models replace the lookup table with a function, which dissolves the mᵏ problem and replaces it with a design choice: what does the model carry from step to step? Sorting the architectures by that answer is more illuminating than sorting them by year.

The argument this table is really about

A transformer with full attention is still a Markov process — the next token depends only on the current KV cache and the last token, with no further reference to history. What makes it different is that its state grows with time. That is the trade in Figure {{fig-augment}} pushed to its limit: never compress, and you never lose anything; pay linear memory and linear per-token compute for the privilege.

State-space models take the opposite end. S4, Mamba, RWKV and linear attention all carry a fixed-size recurrent state, which makes generation O(1) in memory per token and makes the model an honest, classical Markov chain over a learned state — row 5 of Figure {{fig-augment}}, at scale. The cost is equally clean: a bounded state cannot hold an unbounded number of distinguishable facts, so tasks that require verbatim recall of an arbitrary earlier token degrade in a way attention does not. The pragmatic industry answer as of 2026 is a hybrid stack — mostly recurrent or windowed layers, with a few full-attention layers retained precisely for exact recall — which is an explicit statement that neither end of the table is correct on its own.

The useful way to read any new architecture, then, is to ask the §5 question of it: what is the state, how large is it, and what does it throw away? Every answer on that table has been chosen, and each one is a position on the same trade Markov modelling has always posed.

Two more chains in the same stack

Speculative decoding exploits the memorylessness of the decoding loop directly. A small draft model proposes several tokens; the large model scores them all in one parallel pass; an acceptance rule keeps the longest prefix and resamples at the first rejection from an adjusted distribution. The rule is a rejection-sampling argument, and what it buys is exactness: the accepted sequence is distributed exactly as if the large model had generated it alone. Diffusion models are Markov chains twice over. The forward process is a fixed chain that adds calibrated Gaussian noise over many steps until the data is indistinguishable from noise — no learning involved, and the schedule is chosen so that any step can be sampled in closed form. The reverse process is a learned chain that removes it. Sampling an image is running that chain, and the original DDPM formulation used a thousand steps, which is why every subsequent advance — distillation, consistency models, flow matching — has been an attempt to shorten a Markov chain without changing where it ends up. from the literature
