{{S}}The commercial edge, and the ecosystem around it

Providers were always separate processes. What changed after 1.13 is that the commercial features joined them. Terraform Stacks and Terraform Policy are both reached from the CLI, and both run as plugins that core starts with go-plugin, the same machinery Part 2 took apart for providers. Neither engine is in the repository as an engine you can run locally. This section's claim: Terraform's direction is open core plus out-of-process commercial engines.

Stacks: a shim and a download

terraform stacks is a shim. The command's doc comment says it "delegates all execution to an internal plugin" (internal/command/stacks.go:34-35). The plugin is found by service discovery, stackspluginServiceID = "stacksplugin.v1" on defaultHostname = "app.terraform.io", reached over go-plugin with the cookie key TF_STACKS_MAGIC_COOKIE, and the command has its own exit codes: 98 if the plugin cannot be downloaded, 99 for an RPC error (stacks.go:46-75) from the code. The first terraform stacks -help, run with HOME pointed at a scratch directory, downloaded tfstacks 1.4.0, 22,585,528 bytes, into ~/.terraform.d/stacksplugin/, and printed sub-commands such as init, validate, create, list and fmt measured here. The downloaded binary was deleted afterwards.

The odd part is that the Stacks language and runtime are public. internal/stacks holds about 31,260 non-test Go lines in the BUSL tree, with stackconfig, stackplan, stackruntime and the .tfcomponent.hcl file type. A hidden rpcapi command bypasses the CLI's command package entirely; its README still calls the API experimental for the "Stacks private preview", although Stacks went GA on HCP Terraform in September 2025. The README is stale from the code.

Policy: an engine from $PATH

Terraform Policy is GA in the v1.17.0 CLI (Part 3 traces how it got there), and its engine is still not in the repository. internal/policy/client.go:128-142 from the code: 

	cmd := exec.CommandContext(ctx, pgm, "rpcapi")
	plugin := plugin.NewClient(&plugin.ClientConfig{
		HandshakeConfig: plugin.HandshakeConfig{
			ProtocolVersion:  1,
			MagicCookieKey:   "TF_POLICY_PLUGIN",
			MagicCookieValue: "6F11ED78A2AB",
		},
		Plugins: map[string]plugin.Plugin{
			"policy": new(policy),
		},
		Cmd:      cmd,
		AutoMTLS: true,
		AllowedProtocols: []plugin.Protocol{
			plugin.ProtocolGRPC,
		},

pgm defaults to "tfpolicy-plugin" on $PATH, or the path in TF_POLICY_PLUGIN (client.go:116-126). The environment variable's name doubles as the magic-cookie key. The CLI never downloads the plugin. tfpolicy and tfpolicy-plugin 0.5.0 are separate releases on releases.hashicorp.com, each shipped with EULA.txt and TermsOfEvaluation.txt, and the plugin's help says it "executes Sentinel as an RPC API server" measured here (not re-run by a verifier). The protocol is small: Setup, EvaluateResource, EvaluateProvider, EvaluateModule, and a reverse CallbackService through which the engine can ask core for resources and data sources. It runs at three stages. At init, module- and provider-install hooks send each source and version to the engine and block the download on an error. In plan and apply, each instance's attrs and prior_attrs go to EvaluateResource from a separate policy subgraph whose nodes run even after their dependencies fail, under a TF_POLICY_PARALLELISM (or GOMAXPROCS) semaphore from the code.

Whether a failure stops the run depends on the stage. That asymmetry, and the entitlement check that makes local enforcement impossible with plugin 0.5.0, are measured on the project in section 7. Figure 23 puts the three kinds of plugin side by side.

What the big providers are made of

The providers on the shared seam are hybrids. The aws 6.70.0 and google 8.8.0 binaries link terraform-plugin-sdk/v2 v2.40.1 and terraform-plugin-framework v1.19.0, joined by terraform-plugin-mux v0.23.1, and azurerm 5.10.0's symbol paths show the same mix (framework 354 paths, sdk/v2 62, mux 34, plugin-go 73; built with go1.26.9); random 3.9.1 is framework-only measured here. HashiCorp's plugin docs send new providers to the framework and call SDKv2 the "legacy SDK"; mux exists so a provider can move from one to the other resource by resource from the docs. SDKv2 2.41.0 came out on 2026-10-06, so the three cached clouds are one SDK release behind.

Scale, dated

On 2026-10-23 the Terraform Registry's v2 API reported 7,536 providers (34 official, 394 partner, 7,093 community, which sums to 7,521 for a reason not found) and about 24.9 thousand modules, 233 of them verified. hashicorp/aws showed about 8.1 billion downloads across 513 versions. The author's tally of the OpenTofu Registry's index files gives 4,804 provider entries, 226 of them aliases, and 24,140 modules (not re-checked). GitHub showed about 50.1 thousand stars for hashicorp/terraform and 30.6 thousand for opentofu/opentofu. All of these are live counters; they changed during the day they were read from the docs.

The neighbours

Around Terraform sit tools that either reuse its providers or read its files from the docs. Pulumi (Apache-2.0) supports general-purpose languages and loads Terraform and OpenTofu providers through its bridge. Crossplane (Apache-2.0, graduated in CNCF on 2025-10-28) reconciles continuously in a cluster and gets providers from Upjet. CloudFormation is AWS-only and Bicep compiles to ARM JSON. Around the CLI: TFLint (MPL-2.0) catches cloud-specific errors validate cannot, Checkov and Trivy (Apache-2.0; tfsec was folded into Trivy) scan configurations and plan JSON, Terragrunt (MIT, v1.0.0 on 2026-03-30) orchestrates Terraform or OpenTofu, Terratest (Apache-2.0) tests real infrastructure where mock_provider tests none, and Infracost, Atlantis and terraform-docs cover cost, pull-request automation and module docs. Of the tools surveyed, only Terraform core is BUSL.

The stated direction matches the plugin picture. Terraform 1.14 added list resources, query and actions; HashiConf 2025 announced Stacks GA and public betas of search and actions in HCP Terraform; tfpolicy entered an HCP public beta on 2026-07-16 and went GA in the v1.17.0 CLI; HashiCorp's Terraform MCP server, an MPL-2.0 repository, was announced GA in June 2026. OpenTofu, for its part, says it plans to fold policy enforcement into its experimental built-in linting, inside the binary from the docs. HashiConf 2026 (26 to 29 October) falls after these sources were read.
